# media-watch

Let AI agents actually **watch** videos.

`watch_video` takes a link (Instagram reel, TikTok, YouTube/Shorts, Facebook, X, Reddit, …) or a local
file, downloads it with **yt-dlp**, makes a small 480p proxy with **ffmpeg**, sends it to a
video-native model (**Gemini 3.8 Flash via OpenRouter**), and returns a structured report the calling
agent can reason over:

```json
{ "summary": "...", "answer": "...", "content_type": "reel",
  "timeline": [{"start_s": 0, "end_s": 1.5, "description": "..."}],
  "on_screen_text": ["..."], "speech": "...", "audio": "...",
  "notable_moments": [{"t_s": 4.1, "label": "...", "why": "..."}],
  "uncertain": ["..."] }
```

Phase 1 of a larger plan. Next up is a gaming-montage editor (audio-peak detection → model-ranked
highlights → EDL → ffmpeg render with music + SFX) built on the same core.

## Layout

```
mediawatch/        core library (no Hermes imports)
  config.py        Settings from env — no secrets in code
  fetch.py         URL → yt-dlp → cache   |  local path → used in place
  prep.py          ffprobe + 480p proxy (kept under the ~20 MB inline request limit)
  watch.py         OpenRouter call, strict JSON schema, pydantic validation, retry + fallback model
  usage.py         SQLite usage log (cost, tokens, latency, cache hits, errors, prompt version)
  cli.py           `mw watch …`, `mw stats`
plugin/            Hermes plugin — registers `watch_video` (toolset `media`)
tests/             pytest; OpenRouter is mocked, test video is generated by ffmpeg
```

## Install (Hermes)

```bash
git clone git@github.com:hunterbrewer04/media-watch.git ~/Code/media-watch
ln -s ~/Code/media-watch/plugin ~/.hermes/plugins/media-watch
hermes plugins enable media-watch
# restart the gateway / dashboard so it loads, then the `media` toolset is on by default for new plugins
```

Requirements: `ffmpeg`/`ffprobe`, `yt-dlp`, `OPENROUTER_API_KEY` in `~/.hermes/.env`. Hermes' own
Python already ships `httpx` and `pydantic`. `node` (or deno) on the box lets yt-dlp solve YouTube's
JS challenges.

## CLI

```bash
python -m mediawatch.cli watch "https://www.instagram.com/reel/…" -q "what's the recipe?"
python -m mediawatch.cli watch ~/clips/goal.mp4 --detail high --json
python -m mediawatch.cli stats --days 30
```

The CLI reads `OPENROUTER_API_KEY` from the environment, falling back to that single key in
`~/.hermes/.env`.

## Configuration

All optional except the API key — see `.env.example`.

| Variable | Default |
|---|---|
| `OPENROUTER_API_KEY` | — (required) |
| `MEDIA_WATCH_MODEL_NORMAL` | `google/gemini-3.8-flash` |
| `MEDIA_WATCH_MODEL_HIGH` | `google/gemini-3.1-pro-preview` |
| `MEDIA_WATCH_MODEL_FAST` | `google/gemini-3.1-flash-lite` |
| `MEDIA_WATCH_FALLBACK_MODEL` | `qwen/qwen3.8-omni-flash` (empty disables) |
| `MEDIA_WATCH_MAX_SECONDS` | `600` |
| `MEDIA_WATCH_HOME` | `~/.hermes/cache/media-watch` (proxies, reports, `usage.db`) |
| `MEDIA_WATCH_COOKIES` | `~/.config/media-watch/cookies.txt` if present |

## Model choice (tested 2026-10-09)

| Model | Latency | Cost (5.6s clip) | Notes |
|---|---|---|---|
| `google/gemini-3.8-flash` | 5s | $0.0025 | accurate, timestamps, SFX/lyrics/on-screen text — **default** |
| `qwen/qwen3.8-omni-flash` | 20s | $0.0007 | most detailed, slow — fallback |
| `google/gemini-3.1-flash-lite` | 3s | $0.0005 | hallucinated an event — `fast` tier only |

Real-world cost with the structured prompt: ~$0.004–0.011 per video under ~75s.

| Source | Status |

## Cost tracking

Every call (including failures and cache hits) lands in `usage.db`:
`ts, caller (Hermes profile), source, site, video_seconds, model, detail, prompt_version, question,
prompt/completion tokens, cost_usd (exact, from OpenRouter), latency, fetch/prep time, cache_hit,
fallback_used, ok, error`. Requests are also tagged `X-Title: media-watch` so they're separable on
the OpenRouter activity page.

```bash
python -m mediawatch.cli stats
# Last 7 days: 11 calls (6 ok, 1 cached, 0 fallback) · $0.0297 · 2.3 min of video · avg 9.1s
```

## Caching

- Downloads + proxies are cached per canonical URL (tracking params like `igsh`, `utm_*` stripped)
  or per local file fingerprint.
- Reports are cached per (video, model, question, prompt version): asking the same thing twice is
  free; a new question re-uses the proxy and only pays for the model call.

## Security

- No secrets in the repo. Keys come from the environment / Hermes' profile-aware secret lookup.
- `.gitignore` blocks `.env*`, cookies files, databases and media. CI runs gitleaks on every push.
- Video bytes go only to OpenRouter (and its upstream provider). Nothing is uploaded elsewhere.
